Lesson 4.1 — Claude Projects: Your AI Work Brain
Best first step for any product/engineering workflow · No setup required
45 min

Claude Projects give you a persistent AI assistant that remembers your documents, role, writing style, and preferences across conversations. This is the closest thing to a "no-code agent" available today. For product and engineering work, set up separate projects for: PRD work, code review, research, and customer feedback analysis.

⚡ claude.ai → Projects tab 📖 Anthropic Academy — Building with Claude
🛠 Setting Up Your Product PM / Engineering Project
  1. 1
    Create a new Project in Claude.ai called "Product Work" or "Engineering Assistant"
  2. 2
    Add a System Prompt: "You are a senior product manager / staff engineer assisting me. My company is [X]. My role is [Y]. When writing, match my tone: [direct/formal/casual]. Always ask clarifying questions before writing long outputs."
  3. 3
    Upload key context docs: product strategy doc, engineering principles, brand voice guide, recent PRDs, team structure
  4. 4
    Add your best prompts as Artifacts in the project so they're always accessible
  5. 5
    Test with a real task: "Write a PRD for [feature]" — see how it uses your context
✏️ Exercise
Set up one Claude Project for your primary use case (PRD work, code review, or research). Use it for 5 tasks in one week. Note what the persistent context improved vs. starting fresh each time.

Lesson 4.2 — n8n: Build Your First Multi-Step AI Workflow
No-code agent building · Connects AI to 400+ tools
90 min

n8n is a visual workflow builder (like Zapier but more powerful and free). It lets you connect triggers (webhook, schedule, email) → processing (AI via Claude/OpenAI API) → actions (Slack, Jira, Google Sheets, email). This is how you build the "automated competitive analysis" or "ticket summarizer" from your AGENT Framework design.

🛠 n8n.io (free cloud trial or self-host) 🛠 Make.com (free tier) 📖 n8n + AI nodes docs
🤖 Example: "Automated Jira Ticket Summarizer" Workflow
  1. 1
    Trigger: Schedule (every Monday 8am) or Webhook (new Jira ticket created)
  2. 2
    Fetch: Jira node → get all tickets in "Needs Review" status
  3. 3
    AI process: Claude API node → "Summarize these tickets. For each: one sentence summary, priority (High/Med/Low), and suggested assignee based on the description. Output as a formatted list."
  4. 4
    Output: Slack node → post to #product-standup with the summary (pending human review button)
  5. 5
    Human gate: Wait for a team member to click "Approve and post" before it goes anywhere customer-facing
✏️ Exercise — Build Your First n8n Workflow
Start with the simplest possible version of your AGENT Framework workflow from Module 3. A good first workflow: (1) Scheduled trigger, (2) HTTP request to fetch data (or paste data manually), (3) Claude API call to process it, (4) Send result to email or Slack as a draft.

Lesson 4.3 — Google / Microsoft Workspace AI Agents
Zero infrastructure · Works inside tools you already use
60 min

If you're in a corporate environment, you likely already have Gemini in Google Workspace or Microsoft Copilot. These tools let you build AI agents directly inside Docs, Sheets, Gmail, and Teams without any infrastructure. For engineering teams, GitHub Copilot Workspace (currently in beta) goes further — it can plan and implement multi-file code changes.

🤖 Google Workspace Studio (Gemini) 🤖 Microsoft Copilot Studio 💻 GitHub Copilot Workspace
✏️ Exercise
Check whether your company has a Google Workspace or Microsoft 365 AI license. If yes: build one Workspace automation that replaces a manual step in your workflow. Common wins: auto-summarize new emails into a Google Sheet, generate meeting agendas from calendar events, or auto-draft replies to common ticket types.

Lesson 4.4 — Optional: First Steps Into the Claude API
Optional but powerful · 20 lines of Python unlocks everything
90 min

Even if you're not a software engineer, a tiny amount of Python gives you dramatically more flexibility than any no-code tool. The Claude API is exceptionally well-designed and the SDKs handle all the complexity. AI itself can write 90% of the boilerplate — you just need to understand enough to modify and run it.

🎓 Anthropic Academy — "Building with the Claude API" 🎓 DeepLearning.AI — "Agent Skills with Anthropic" 📖 Claude API Quickstart
Minimum viable Claude API call (Python)
import anthropic client = anthropic.Anthropic(api_key="your-api-key") # Replace this with your actual task my_document = """[PASTE YOUR DOCUMENT HERE]""" message = client.messages.create( model="claude-sonnet-4-6", max_tokens=1024, messages=[ {"role": "user", "content": f""" You are a senior product manager. Analyze this document and extract: 1. Key decisions 2. Action items with owners 3. Open risks Document: {my_document} """} ] ) print(message.content[0].text)
Run this with: pip install anthropic then python script.py
