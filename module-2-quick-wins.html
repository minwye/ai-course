Lesson 2.3 — Writing, PRDs & Technical Communication
11.4 hours saved per week on average · Immediate payback
60 min

The highest-value writing use cases for product/engineering: PRD drafts from research notes, release notes from commits, RFC first drafts, status updates, and technical blog posts. The key technique is "bones then flesh" — generate structure first, then fill each section. Don't ask AI to write everything from scratch with no context.

Open the Prompt Library now — it has ready-to-use templates for every writing task listed above.

Lesson 2.4 — Meeting Intelligence (Bonus Quick Win)
80% time reduction · 2–3 hours saved per week
30 min

This is the single fastest win for most knowledge workers. Set up Fathom (free), Otter.ai, or Fireflies to auto-record, transcribe, and extract action items from every meeting. For standup and sprint planning notes specifically, use the structured extraction prompt below.

🎙 Fathom — Free, excellent quality 🎙 Otter.ai — Free tier available 🎙 Fireflies.ai — Integrates with Jira
✏️ Setup Exercise
Install Fathom (free) and connect it to your calendar. Use it for your next 3 meetings. For each meeting, see how long the summary takes vs. your manual notes. If you paste a transcript into Claude, use this prompt:
You are an expert meeting facilitator. Given this transcript, extract: 1. Decisions made (numbered, clear owner if stated) 2. Action items (Owner | Action | Due date) 3. Key discussion points (3–5 bullets) 4. Open questions / parking lot 5. Next steps Be concise. Flag anything unclear with [UNCLEAR].
